# Mobile Apps Distribution Page

A React website for browsing and downloading Android APK applications created by Ashish Ranjan.

## Live Website

https://a2rp.github.io/mobile-apps-distribution-page/

## Features

- Browse apps by category
- Direct APK downloads
- Release notes links
- Responsive design
- GitHub Pages deployment
- Refresh-safe React routes

## Tech Stack

- React
- Vite
- React Router
- Styled Components
- React Icons

## Getting Started

```bash
git clone https://github.com/a2rp/mobile-apps-distribution-page.git
cd mobile-apps-distribution-page
npm install
npm run dev
```

## Available Commands

```bash
npm run dev
npm run lint
npm run build
npm run preview
npm run deploy
```

## App Data

Application details are stored in:

```text
public/data/apps.json
```

Application icons are stored in:

```text
public/apps/
```

## APK Releases

APK files are available from:

https://github.com/a2rp/mobile-apps-releases
